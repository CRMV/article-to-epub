## Chrome Web Store Listing

Public name:

```text
Article to EPUB
```

Short description:

```text
Send web articles to Kindle as EPUB.
```

Detailed description:

```text
Article to EPUB converts the current web article into a clean EPUB file you can download and send through Amazon-supported document routes.

Use it when a web article is worth reading away from the browser. The extension captures the active page after you click it, builds a readable local preview, lets you edit title, author, date, and source metadata, and shows image and file-size warnings before export.

Features:
- Convert the active article page into a Kindle-ready EPUB
- Preview the article before generating the file
- Edit metadata before download
- Choose image handling modes for smaller or richer files
- Save reusable local Kindle/profile preferences
- Download the EPUB for Send to Kindle web upload or approved-sender email

Privacy:
Article to EPUB processes article content locally in the browser extension. It has no backend, no analytics, no remote crash reporting, and no automatic diagnostic upload.

Article to EPUB is not affiliated with Amazon. It does not automate Amazon login, use Amazon credentials, access Amazon cookies, or call private Amazon delivery endpoints.
```

## Permission Justifications

`activeTab`:

```text
Used only after the user clicks the extension to read the current page and prepare an article preview.
```

`scripting`:

```text
Injects a page snapshot script into the active tab after user action so the extension can extract the article content.
```

`sidePanel`:

```text
Shows the local preview, metadata editor, image controls, conversion warnings, and delivery handoff options.
```

`storage`:

```text
Saves local preferences, Kindle/profile choices, and optional user-entered handoff settings in the browser.
```

`downloads`:

```text
Saves the generated EPUB file to the user's computer.
```

`optional_host_permissions`:

```text
Requested only when needed to include cross-origin article images in the generated EPUB.
```
